Веб-приложение для заказа доставки на ASP.NET Core с использованием Entity Framework Core для работы с базой данных. Реализованы аутентификация и авторизация пользователей (пароли хранятся в виде хешей) и управление настройками аккаунта. Корзина работает как для гостей, так и для авторизованных пользователей: без входа можно добавлять и удалять товары, а после входа корзина загружается в БД. Стоимость доставки рассчитывается с учётом расстояния до пользователя, адрес можно добавить с помощью подсказок. Приложение использует API: Geoapify (расcчитывает расстояние для доставки) и Dadata (подсказки адресов).
